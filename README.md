# RouteTogether

Share live locations with your trip group on one map.

1. Open the app link on your phone, enter your name, tap **New trip**, then **Join trip**.
2. Tap **Invite friends** and send the link on WhatsApp. Friends open it, type their name and join.
3. Tap **Set meeting point**, then tap the map. Everyone sees their distance to it, and the app announces arrivals.

Keep the page open while travelling: phone browsers pause location sharing when the screen is locked.

## Run locally
```
npm install
npm start   # http://localhost:3000
```

Built with Node.js, Express, Socket.io, Leaflet and OpenStreetMap.
